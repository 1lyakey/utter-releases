# Utter — releases

Utter is a Windows dictation tool: hold a key, speak, release — the text lands at the caret of the active window.

This repository only hosts the builds. Download `Utter-Setup.exe` from the latest release and run it; the program installs itself to `%LOCALAPPDATA%\Utter` and later updates from here on its own.

Each release ships `update.json` with the version and the SHA-256 of the exe. The program checks that hash before replacing itself.
